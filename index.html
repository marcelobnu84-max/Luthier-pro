Firebase (status online para o cliente)

Com Firebase gratuito, o cliente consulta o status do instrumento de qualquer celular. Crie um projeto em console.firebase.google.com, ative o Firestore, cole a configuração abaixo e sincronize.

Firebase: não configurado

Regras do Firestore (cole no Firebase → Firestore → Regras) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /portal/{doc} {
      allow read: if true;
      allow write: if true;
    }
    match /servicos/{id} {
      allow read: if true;
      allow write: if true;
    }
    match /agendamentos/{id} {
      allow read: if true;
      allow write: if true;
    }
  }
}

Depois publique as regras. (Para uso só da sua oficina o free costuma bastar.)
